## Recording
This lesson is intended to be given asynchronously. You may view the assigned recording [here](https://youtu.be/F1X3syx7Jdg).


## Learning Objectives

*After this lesson, students will be able to:*

1. Conversationally discuss Big O notation in relation to algorithm speed
1. Recognize some data structures are better suited to some tasks than others

## Lesson Outline

I. **Slide Deck**
- What is an "algorithm"?
- Landau's Big O Notation
- Data structures
- Motivating example: arrays vs linked lists
- Motivation example: binary search

II. **Notebook**
- Generate large data and carry out linear search
- Define a binary node class and carryout binary search
- Compare results
